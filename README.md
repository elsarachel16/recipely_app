# Recipely 🍽️

A modern Flutter Web recipe platform built with Firebase Authentication and Firebase Hosting.

## Features

* User Authentication (Firebase)
* Login & Sign Up
* Recipe Search
* Detailed Recipe Pages
* Responsive Design
* Notifications Page
* Modern Mint-Green UI
* Firebase Hosting Deployment

## Tech Stack

* Flutter
* Firebase Authentication
* Firebase Hosting
* Google Fonts
